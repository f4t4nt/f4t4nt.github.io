# GRAPH STRUCTURE
# ---------------
# 104 vertices, 208 undirected edges, every vertex of degree 4, every pair of
# vertices within 4 steps of each other.
#
# The graph has three identical blocks, A, B and C. Each is a subdivided
# K_4,4: four L branches, four R branches, and a port Pxy subdividing the
# edge between Lx and Ry.
#
#   block A: A.L0..A.L3, A.R0..A.R3, A.P00..A.P33
#   block B: B.L0..B.L3, B.R0..B.R3, B.P00..B.P33
#   block C: C.L0..C.L3, C.R0..C.R3, C.P00..C.P33
#
# The other 32 vertices are connectors, in 16 matched pairs: X00a/X00b
# through X15a/X15b. A connector runs one edge to its partner and one into
# each block, so it too has degree 4; a port is subdividing an L-R edge and
# takes two connectors, so it does too.
#
# The edge list is grouped as follows:
#   1. Internal L-P and R-P edges for blocks A, B, and C (96 edges)
#   2. Connector-to-port edges for blocks A, B, and C (96 edges)
#   3. Connector matching edges (16 edges)
