Jane Street ASIC Puzzle 2026

My solution to Jane Street’s ASIC reverse-engineering puzzle.

We reverse engineer the ASIC by 1) recovering electrical wires from touching conductor polygons, 2) identifying standard cells joined by those wires, 3) translating the cells into Boolean equations, and 4) expanding the clocked circuit over time for Z3 to solve. We first validate this process on the warm-up and then apply it to the puzzle to retrieve the desired 121-bit input that, when written as an 11×1111\times1111×11 Star Battle-inspired grid, has two stars per row, column, and region. Given this input, the ASIC prints (* TWO STARS *).

Introduction

All computers deal in bits, and this ASIC is no different. The ASIC incrementally takes in 121 input bits and applies a deterministic procedure to them. We wish to find an input that turns on the success signal. This sounds like a Boolean satisfiability problem.

Directly solving the supplied ASIC is a daunting task, so instead we set out to solve the warm-up GDS, using its published behavior to test our process. Once our process is established, we repeat it with the ASIC.

The warm-up as a running example

The warm-up describes two 8-bit registers, a 9-bit adder, and a comparison with 496. On every rising clock edge for which en=1, 1 bit from A and 1 from B enter the two registers. After 8 edges, the register values are summed in the adder and the result is compared to 496, turning SSS on iff equal. This is succinctly described as

S=[ a7:0+b7:0=496 ],S = [\,a_{7:0}+b_{7:0}=496\,],S=[a7:0​+b7:0​=496],

where brackets mean a Boolean truth value. Figure 1 shows this circuit.

The sample tests shift bits in order from most significant to least significant. They first check a positive example, 250+246=496250+246=496250+246=496, then a negative example, 1+2≠4961+2\neq4961+2=496. We shall use these values to test our recovered circuit.

We can inspect the conducting polygons and contacts either separately or as a stack. The contacts join conductors on adjacent layers; these vertical connections are as important as intersections within a layer.

def triangulate(pts):
    if len(pts) == 4:
        return np.array([(0, 1, 2), (0, 2, 3)], np.uint32)
    return mapbox_earcut.triangulate_float64(np.asarray(pts, np.float64),
                                             np.array([len(pts)], np.uint32)).reshape(-1, 3)

def prism_mesh(polys, zlo, zhi):
    V, F = [], []
    for pts in polys:
        n, base = len(pts), len(V)
        V += [(x, y, zlo * ZS) for x, y in pts] + [(x, y, zhi * ZS) for x, y in pts]
        for a, b, c in triangulate(pts):
            F += [(base + a, base + c, base + b), (base + n + a, base + n + b, base + n + c)]
        for i in range(n):
            j = (i + 1) % n
            F += [(base + i, base + j, base + n + j), (base + i, base + n + j, base + n + i)]
    return np.array(V, np.float32), np.array(F, np.uint32)

def rect_clip(pts, x0, y0, x1, y1):
    for axis, lim, sgn in ((0, x0, 1), (0, x1, -1), (1, y0, 1), (1, y1, -1)):
        kept = []
        for i in range(len(pts)):
            a, b = pts[i - 1], pts[i]
            da, db = sgn * (a[axis] - lim), sgn * (b[axis] - lim)
            if (da >= 0) != (db >= 0):
                t = da / (da - db)
                kept.append((a[0] + t * (b[0] - a[0]), a[1] + t * (b[1] - a[1])))
            if db >= 0: kept.append((b[0], b[1]))
        pts = kept
        if len(pts) < 3: return None
    return pts

Identifying this geometry lets us recover the wires.

What the DSU represents logically

Our extractor gives an integer ID to each conductor polygon. A disjoint-set union (DSU) maintains groups of IDs. At first, every polygon is alone. We do union(a,b) if 1) polygons aaa and bbb intersect on the same conducting layer, or 2) a via cut intersects aaa and bbb. After all unions are completed, find(a)\texttt{find(a)}find(a) returns the same ID as find(b)\texttt{find(b)}find(b) iff aaa and bbb are connected through such contacts.

We treat each equivalence class as one ideal electrical node, called a net. Note that the DSU records only connectivity; it does not record logical operations, time, direction, or a signal's value.

In the worked example below, the DSU groups 13 conductor drawing polygons on 3 layers through 8 same-layer contacts and 4 via cuts, and attaches 2 cell endpoints. Four overlapping pin shapes bring the extractor's count to 17; they add no new conducting area. The 3 layers are drawn separately in Figure 5 to make the contacts visible.

The recovered nets can also be inspected in the original geometry. The conductor view includes pin shapes as well as drawing polygons; the full stack supplies their physical context.

class DSU:
    def __init__(s, n): s.p = list(range(n))
    def find(s, a):
        r = a
        while s.p[r] != r: r = s.p[r]
        while s.p[a] != r: s.p[a], a = r, s.p[a]
        return r
    def union(s, a, b):
        ra, rb = s.find(a), s.find(b)
        if ra != rb: s.p[rb] = ra

From named cells to Boolean equations

Connectivity tells us which pins share a wire, but cell semantics tell us what those pins compute.

Standard cells, masters, and instances

This design does not lay out transistors gate by gate. It assembles circuits from small, pre-designed components such as AND gates, multiplexers, and flip-flops, each stored once in the GDS as a definition and then placed wherever it is needed. Those definitions have names beginning sky130_fd_sc_hd__.

For example, one embedded definition is named

sky130_fd_sc_hd__mux2_1.\texttt{sky130\_fd\_sc\_hd\_\_mux2\_1}.sky130_fd_sc_hd__mux2_1.

The mux2 identifies a 2-input multiplexer, and the 1 identifies its drive-strength variant. Drive strength does not affect the Boolean rule, so we will ignore it. We call a reusable GDS definition a master; an instance is one such placed copy of it. In the warm-up, sr_a/_11_ is an instance of the mux2_1 master.

The master defines 4 signal pins:

PinDirectionMeaning
A0inputvalue selected when S=0
A1inputvalue selected when S=1
Sinputselection bit
Xoutputselected value

Consequently, sr_a/_11_.X means “pin X on this particular placed mux.”

Substituting nets into a documented cell rule

Our geometric reconstruction attaches the 4 pins of this instance to the following nets:

sr_a/_11_.A0⟼n28,sr_a/_11_.A1⟼n79,sr_a/_11_.S⟼n80,sr_a/_11_.X⟼n237.\begin{array}{ccc} \texttt{sr\_a/\_11\_.A0} & \longmapsto & n28,\\ \texttt{sr\_a/\_11\_.A1} & \longmapsto & n79,\\ \texttt{sr\_a/\_11\_.S} & \longmapsto & n80,\\ \texttt{sr\_a/\_11\_.X} & \longmapsto & n237. \end{array}sr_a/_11_.A0sr_a/_11_.A1sr_a/_11_.Ssr_a/_11_.X​⟼⟼⟼⟼​n28,n79,n80,n237.​

Each net carries a Boolean value. The 3 input pins read the values on n28n28n28, n79n79n79, and n80n80n80; the output pin drives the result onto n237n237n237. A mux operates under the following rule:

X={A0,S=0,A1,S=1.  ⟺  n237={n28,n80=0,n79,n80=1.X = \begin{cases} A0,&S=0,\\ A1,&S=1. \end{cases} \iff n237 = \begin{cases} n28,&n80=0,\\ n79,&n80=1. \end{cases}X={A0,A1,​S=0,S=1.​⟺n237={n28,n79,​n80=0,n80=1.​

Equivalently,

n237=ite⁡(n80,n79,n28)=(n80∧n79)∨(¬n80∧n28),n237 = \operatorname{ite}(n80,n79,n28) = (n80\land n79)\lor(\neg n80\land n28),n237=ite(n80,n79,n28)=(n80∧n79)∨(¬n80∧n28),

where ite⁡(c,x,y)\operatorname{ite}(c,x,y)ite(c,x,y) means “if ccc, then xxx, otherwise yyy.”

In this example, n80n80n80 is connected to the top-level input en. When en=1, the mux passes n79n79n79, the output of the preceding shift-register stage, toward the next flip-flop. When en=0, it passes n28n28n28 back, which is that flip-flop's own output, so the flip-flop retains its current value at the next clock edge.

Translating the remaining cells

We repeat the same substitution for every placed component. For example, a 2-input AND cell obeys

X=A∧B.X=A\land B.X=A∧B.

If one particular instance has A→n3\to n3→n3, B→n12\to n12→n12, and X→n25\to n25→n25, that instance contributes

n25=n3∧n12.n25=n3\land n12.n25=n3∧n12.

An inverter contributes a negation. More complicated cells contribute larger expressions. For example, the documented function of an a21o cell is

X=(A1∧A2)∨B1.X=(A1\land A2)\lor B1.X=(A1∧A2)∨B1.

This process produces Boolean equations for all combinational cells: components whose outputs depend only on their current inputs. Flip-flops require one additional idea because their outputs depend on an earlier clock edge.

Adding memory and the clock

A combinational equation relates values at a specific point in time. A flip-flop introduces state. Specifically, an output Q after a rising edge equals D just before that edge. We therefore index state by clock step. If n28 is the Q output of sr_a/_19_, then

n28t+1={0,if reset is active,n237t,otherwise.n28_{t+1}=\begin{cases} 0,&\text{if reset is active},\\ n237_t,&\text{otherwise}. \end{cases}n28t+1​={0,n237t​,​if reset is active,otherwise.​

Substituting the mux equation yields

n28t+1=ite⁡(ent,n79t,n28t)when reset is inactive.n28_{t+1}=\operatorname{ite}(\texttt{en}_t,n79_t,n28_t) \quad\text{when reset is inactive.}n28t+1​=ite(ent​,n79t​,n28t​)when reset is inactive.

Figure 7 illustrates this rule, both as a circuit and over time.

The mux output n237 changes whenever its inputs change. The flip-flop copies n237 into n28 only at a rising clock edge, then holds it. Thus the clock marks when the transition equation applies. Pulling reset low overrides the clock and forces n28 to 0.

class Sim:
    def __init__(s, eqs, ffs, ports, n_nets):
        s.ffs, s.ports, s.n = ffs, ports, n_nets
        s.compiled = {}
        for net, (expr, ins, sn) in eqs.items():
            args = sorted(ins)
            fn = eval('lambda ' + ','.join(args) + ': (' + expr + ')&1' if args
                      else 'lambda: (' + expr + ')&1')
            s.compiled[net] = (fn, [ins[a] for a in args])
        sources = {q for q, *_ in ffs} | set(ports.values())
        s.order, placed, remaining = [], set(sources), dict(eqs)
        while remaining:
            ready = [n for n, (e, ins, sn) in remaining.items()
                     if all(i in placed or i not in eqs for i in ins.values())]
            assert ready, 'combinational cycle'
            for n in ready:
                s.order.append(n); placed.add(n); remaining.pop(n)
        s.reset()
    def reset(s):
        s.val = [0] * s.n
        for q, d, rval, rnet, sn in s.ffs:
            if rval is not None: s.val[q] = rval
    def settle(s, inputs):
        for k, v in inputs.items():
            if k in s.ports: s.val[s.ports[k]] = v
        for n in s.order:
            fn, argnets = s.compiled[n]
            s.val[n] = fn(*[s.val[a] for a in argnets])
    def edge(s, inputs):
        s.settle(inputs)
        for q, v in [(q, s.val[d]) for q, d, *_ in s.ffs]: s.val[q] = v
        for q, d, rval, rnet, sn in s.ffs:
            if rnet is not None and s.val[rnet] == 0: s.val[q] = rval
        s.settle(inputs)

def parse_vcd(path):
    ids, cur, edges = {}, {}, []
    in_defs = True
    for line in open(path):
        line = line.strip()
        if in_defs:
            if line.startswith('$var'): ids[line.split()[3]] = line.split()[4]
            if line.startswith('$enddefinitions'): in_defs = False
            continue
        if not line or line[0] in '$#': continue
        if line[0] == 'b':
            v, sym = line.split()
            v = v[1:]
        else:
            v, sym = line[0], line[1:]
        name = ids.get(sym)
        if name is None: continue
        val = None if 'x' in v or 'z' in v else int(v, 2)
        if name == 'clk' and cur.get('clk') == 0 and val == 1: edges.append(dict(cur))
        cur[name] = val
    return ids, edges

Turning a clocked circuit into one finite formula

We give the state vector a separate name at each modeled clock edge and connect adjacent states using the next-state function. We call this unrolling the circuit. This leaves one finite combinational formula.

For the warm-up, applying the transition rule 8 times creates states Q0,Q1,…,Q8Q_{0},Q_{1},\ldots,Q_{8}Q0​,Q1​,…,Q8​. Reset fixes Q0Q_{0}Q0​; the serial input bits at each step are known values; and we evaluate the final expression for S. Because nothing here is unknown, the warm-up is a check rather than a search: SSS comes out 1 for 250+246250+246250+246 and 0 for 1+21+21+2, exactly as the published sample tests require.

The warm-up also ships its routed DEF, which states the true connectivity, so we can compare that against our recovered nets. All 84 signal nets and all 291 endpoints agree: no net is missing an endpoint, none has gained one, none is split into two, and no two are merged into one. Since the recovered circuit agrees with both the sample tests and the DEF, we use the same method on the ASIC.

The ASIC uses exactly this construction, with 1 change: the serial inputs are unknown Boolean variables rather than known bits. Let QtQ_tQt​ be the vector of all 92 flip-flop outputs immediately after edge ttt, and let ItI_tIt​ be the bit presented at the next edge. The transition function TTT evaluates every recovered combinational equation using QtQ_tQt​, ItI_tIt​, and enablet_tt​, then collects the resulting flip-flop outputs. Thus

Recovering the regions

Closer inspection of the 92 flip-flops reveals that 44 lie in 2 regular banks of 22. Tracing their next-state equations pairs each bank into eleven 2-bit counters. One bank is selected by column; the other is selected by an irregular position-dependent signal. Because the 121 bits arrive serially in row-major order, the same 11-column selection schedule is reused for every row.

For a concrete example, one pair has low bit n717 and high bit n509. Simplifying the gates that drive their D pins gives the following behavior, with xxx meaning the current input is 1, capture is enabled, and this particular counter is selected:

xxxold HLnew HLmeaning
0anyunchangedthis cell does not add to the counter
10001first selected star
10110second selected star
110 or 1111third or later star, saturated at 3

Thus the remaining problem is to learn which counter is selected at each of the 121 positions. We reset the circuit and feed 0 for every position before ttt. The position machinery still advances, so the selection signals are correct for position ttt, but no star has been counted anywhere and every counter therefore sits at 00. From 00, a selected counter must move to 01 when it sees a star, while an unselected one cannot move at all. So we copy that pre-edge state and evaluate the next state twice, once with It=0I_t=0It​=0 and once with It=1I_t=1It​=1. For these 2 counter banks, exactly 1 low flip-flop per bank differs between the 2 evaluations, and it is the low bit of the counter selected at position ttt.

For cell (1,1)(1,1)(1,1), the differing low bits are n313 in one bank and n717 in the other. The n313 choice recurs at cells (2,1),(3,1),…(2,1),(3,1),\ldots(2,1),(3,1),…, identifying column 1. At (1,2)(1,2)(1,2) the column bit changes to n304, while the region bit is still n717, so (1,1)(1,1)(1,1) and (1,2)(1,2)(1,2) must share the same region. At (1,6)(1,6)(1,6) the pair is n671 and n495: column 6 and a new region. Repeating this comparison for all 121 stream positions yields the complete partition.

The extracted schedule must pass 4 checks: 11 column selectors repeat every row; 11 region selectors cover all 121 cells exactly once; each resulting region is orthogonally connected; and the winning replay leaves every column and region counter at binary 10. All 4 hold, and the resulting reconstruction is Figure 13.
